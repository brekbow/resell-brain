# eBay

- Biggest buyer pool in resale - and already the comps source for [[pricing-rules]]
- Fees: ~13.25% of sale + $0.40/order (fixed fee stings on cheap items -> prioritize $50+ pieces here)
- Authenticity Guarantee on sneakers $100+ and luxury -> big trust boost on high-end pieces
- Shipping: seller ships. On each sale, buy + print the label through eBay's shipping flow -> [[workflow-sold]]
- Fill ALL item specifics per [[listing-optimization]] - eBay search heavily rewards complete item specifics
- No API - Chrome only, human pace per [[safety-limits]]
